# Ekran Kaydedici (Ravix_w1)

Düşük sistemli bilgisayarlar için geliştirilmiş, hafif bir Electron tabanlı ekran kaydedici.

## Özellikler
*   Hafif yapısıyla düşük sistemlerde (örneğin Casper Nirvana) akıcı kayıt imkanı.
*   FPS seçimi (15, 30 veya özel FPS ayarı).
*   TikTok / Shorts (9:16) ve YouTube (16:9) için otomatik en-boy oranı kırpma.
*   Mikrofon ve sistem sesi karışımı.
*   Olası bir çökme durumunda kaydı kurtarma (Recovery) sistemi.
*   MP4 ve WebM format desteği.

## Nasıl Çalıştırılır? (Geliştiriciler İçin)
Projeyi bilgisayarınıza indirdikten sonra terminalde şu komutları çalıştırın:
```bash
npm install
npm start
